# VPC Networking

## Goal

Build the network foundation for the secure web application.

## What I Did

- Created a custom VPC named `secure-web-vpc`
- Configured VPC CIDR:
  - `10.0.0.0/16`
  - <img width="1550" height="640" alt="image" src="https://github.com/user-attachments/assets/ebf5f0c7-8d87-4b92-b032-9332ed75564b" />

  - `10.0.1.0/24`
  - <img width="1575" height="294" alt="image" src="https://github.com/user-attachments/assets/c124b637-849f-4a15-92f3-1641998c4611" />

- Created a private subnet:
  - `private-subnet-1`
  - `10.0.2.0/24`
  - <img width="1557" height="302" alt="image" src="https://github.com/user-attachments/assets/c89ef3e9-8112-428e-8fe1-4b484a06bd95" />

- Created an Internet Gateway:

- Attached the Internet Gateway to the VPC.
- <img width="1616" height="504" alt="image" src="https://github.com/user-attachments/assets/e53558f6-c929-4086-9f0c-cade3e8bf21c" />

  - `0.0.0.0/0 → Internet Gateway`
- Associated `public-subnet-1` with `public-rt`.
- <img width="1576" height="564" alt="image" src="https://github.com/user-attachments/assets/6e7108eb-7af8-4351-b431-3d54a24380a9" />

  -<img width="1906" height="751" alt="image" src="https://github.com/user-attachments/assets/215b53bb-df71-4039-9932-680e3a97b03b" />

- Created a private route table:
  - `private-rt`
- Added the route:
  - `0.0.0.0/0 → NAT Gateway`
- Associated `private-subnet-1` with `private-rt`.
